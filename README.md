## 🎛️ Core Animation Architectures & Motion Science

1. **Centrifugal Particle Vortex** — Autonomous vector-field fluid dynamics simulation with non-linear drag damping and cursor repulsion.
2. **Volumetric Chromatic Displacement** — Real-time multi-channel RGB split shaders responding to cursor velocity and audio transients.
3. **Momentum Kinetic Typography** — Dynamic velocity-skew matrix (`skewX`) with elastic character flip rolls.
4. **Decoupled Spatial 3.5D Parallax** — Gyroscopic coordinate tracking with incident light sheen angle calculations.
5. **Optical Glass Refraction & Fresnel** — Schlick’s Fresnel approximation, dynamic acrylic backdrop blur, and specular light highlights.
6. **Procedural Native Web Audio Synthesis** — Zero-asset spatial sound engine synthesizing hover frequency sweeps, sub-bass click punches, digital glitch bursts, and a generative dual-oscillator ambient chord drone.
