## 🚀 Key Features

- **Real-Time 3D WebGL Hero Canvas**:
  - Interactive multifaceted icosahedron mesh with custom physical clearcoat iridescence.
  - 2,200 particle starlight galaxy that dynamically repels away from the cursor.
  - Gravitational shockwave propagation on click.
- **10 Dedicated Interactive Labs**:
  - Fully playable sandboxes with live sliders, direct pointer manipulation, and physics triggers.
- **Procedural Web Audio API Synthesizer Engine**:
  - Zero external `.mp3` or `.wav` dependencies.
  - Procedural sound synthesis: tactile hover frequency sweeps, sub-bass click thuds, digital glitch bursts, warp whooshes, and an ethereal generative ambient drone.
- **Studio Performance HUD**:
  - Real-time 60 FPS sparkline frame-latency graph.
  - Time Dilation Speed Controller: `0.3x Slo-Mo`, `1.0x Normal`, `2.0x Warp`.
  - Geometry Shader toggle: `SURFACE MESH` vs `WIREFRAME`.
- **Interactive Terminal Console**:
  - Real functional CLI emulator (`skills`, `awards`, `stack`, `contact`, `clear`).
